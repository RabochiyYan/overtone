ОКНО ОВЕРТОНА — WEBGL

ЛОКАЛЬНЫЙ ЗАПУСК НА MAC
Дважды щёлкните Play-WebGL.command в папке проекта.
Команда проверяет исходники и при необходимости собирает новую WebGL-версию.
Для сервера нужен Python 3; для автоматической сборки — установленный Unity CLI
(в PATH или ~/.unity/bin/unity) и Unity с модулем WebGL.
Если Unity открыт, выйдите из Play Mode: сборка выполняется в этом Editor.
Если Unity закрыт, CLI запускает пакетную сборку сам.
Первая сборка после изменений может занять несколько минут.
Если сборка не удалась, устаревшая игра не открывается.

После успешной проверки откроется http://localhost:8080/?v=<версия>.
Сервер запускается до открытия браузера. Новые файлы имеют имена по хешу
содержимого, а локальный сервер отключает кеширование ответов.
Повторный запуск использует уже работающий сервер этой же сборки.
Если порт занят другим приложением, выбирается следующий свободный.
На другом порте браузер использует отдельное сохранение.
Не закрывайте окно сервера, пока играете. Остановка — Ctrl+C.

ЗАПУСК ИЗ ТЕРМИНАЛА
Откройте терминал в папке overtone и выполните:
python3 Tools/play_webgl.py
Проверить актуальность без сборки и запуска:
python3 Tools/play_webgl.py --check
Для проверки сервера без открытия браузера:
python3 Tools/play_webgl.py --no-browser
Открывать index.html напрямую через file:// нельзя.

ПОВТОРНАЯ СБОРКА
В Unity: Overtone → Build WebGL.
Или запустите Play-WebGL.command: устаревшая сборка обновится автоматически.
Если Editor закрыт, ручная команда из папки overtone:
unity build . --target WebGL --execute-method Overtone.Editor.WebGLBuilder.Build --output ./Builds/WebGL
Если Editor открыт, меню Overtone → Build WebGL применит все настройки сборки.

ХОСТИНГ
Содержимое Builds/WebGL можно загрузить целиком на статический хостинг.
index.html должен остаться рядом с папкой Build.
Gzip и Decompression Fallback включены: специальные Content-Encoding
заголовки для файлов .unityweb не требуются. Не задавайте им gzip вручную.
Публичная публикация не выполнялась.

УПРАВЛЕНИЕ
Мышь / перетаскивание, A/D или стрелки; Esc — пауза.
Кнопка «На весь экран» находится под игрой.
На сенсорных экранах доступны игровые кнопки; удобнее играть
в горизонтальной ориентации на большом экране.
Прогресс хранится в браузере через PlayerPrefs / IndexedDB и зависит
от адреса сайта, порта и профиля браузера. Очистка данных сайта удалит его.
