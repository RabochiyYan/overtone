КАНАЛЫ ВТОРОЙ ФАЗЫ

Редактируйте Assets/Overtone/Resources/PhaseTwoChannels.json.
Все 54 прежних канала уже перенесены в него. Порядок каналов в файле задаёт
порядок номеров в игре. Координаты, группы и связи вручную задавать не нужно.

Пример записи внутри массива channels:
{
  "name": "Новый научный канал",
  "topic": "#наука",
  "platform": "Telegram",
  "camp": 2,
  "audience": 5000,
  "canPublish": true
}

name — название (обязательно).
topic — тематика (обязательно). Одинаковая тематика объединяет каналы в группу.
Регистр, пробелы по краям и начальный # не влияют на группировку.
Новая тематика автоматически создаёт новую группу; удаление последнего канала
убирает группу. Для совпадения с темой новости используйте её название темы.
platform — площадка, произвольная строка.
camp — 0: власть; 1: оппозиция; 2: нейтральный.
audience — целое неотрицательное число подписчиков.
canPublish — true, если канал доступен для стартовой публикации.
Если в группе не осталось стартовых каналов, первым автоматически станет её
первый канал. Исходный JSON при этом не изменяется.

Добавляйте/удаляйте целые записи. Между записями нужна запятая, после последней
запятая не ставится. Пустой список допустим: { "channels": [] }.
Не нужны фиксированное число каналов, идентификаторы или ссылки на номера.

Сеть строится случайно при запуске игры. Каналы одной темы получают связи
гораздо чаще, чем каналы разных тем. Если случайно возникли изолированные
части, генератор добавляет связи, чтобы вся сеть была достижима.
Количество соседей и переходов между темами не фиксировано.

Расположение рассчитывается силами притяжения по связям и отталкивания узлов.
У тематик нет заданных центров, ячеек или границ. Близкие темы могут перемешиваться,
а плотные сообщества складываются из структуры связей. Во время игры связи
и координаты сохраняются: выбор новости и анимация их не пересоздают.

Цвет окружности — тематика; соответствия цветов показаны над картой.
Значок под узлом — лагерь: треугольник вверх (власть), треугольник вниз
(оппозиция), кружок (нейтральный). Номер внутри — порядок канала в файле.
Размер узла зависит от аудитории, сведения о канале открываются при наведении.
Метка СТАРТ над узлом обозначает доступную стартовую публикацию.

По умолчанию карта видна целиком. Кнопки + и − меняют масштаб; ОБЗОР возвращает
всю сеть в кадр. Увеличенную карту можно перетаскивать и прокручивать.
Большое количество тематик прокручивается отдельно в легенде над картой.

Изменения применяются при следующем запуске игры (выход и вход в Play Mode).
Для готовой WebGL/desktop версии после изменения файла нужна новая сборка.
Число каналов технически не фиксировано, но очень большие списки увеличивают
время построения и отрисовки; визуализация создаёт все узлы сразу.
Планы просмотров из PrototypeSettings не масштабируются с размером списка:
при сильном изменении суммарной аудитории их стоит отрегулировать отдельно.

НАСТРОЙКИ В ИГРЕ

В панели создания новости есть кнопка «Настройки сети и сложности».
Окно доступно перед публикацией. Ползунки меняют черновик; «Применить»
обновляет параметры, «Отмена» или Escape отменяет правки.
«По умолчанию» восстанавливает исходные значения в черновике.

Сложность: 0,1–3 от плана текущего задания; справа показано количество
просмотров. Множитель действует и на планы следующих заданий.
Каналы: от 1 до 300 (или до размера исходного списка, если он больше).
При уменьшении выбираются каналы из разных частей списка. При увеличении
создаются варианты исходных каналов с суффиксами. Сам JSON не меняется.
По умолчанию используется весь список, включая последующие изменения файла.
Связность: желаемое среднее число связей, от 2 до 12. На очень маленькой
сети предел — количество остальных каналов. Значение по умолчанию 3,55
сохраняет прежний случайный генератор и может немного отличаться от
фактического среднего. Прочие значения задают число рёбер сети напрямую.
Перемешанность тем: 0 % — почти замкнутые темы, 100 % — случайные связи
независимо от темы. По умолчанию 10 % соответствует прежнему предпочтению тем.
Группировка по лагерям: от 0 % (не влияет) до 100 % (сильное предпочтение
связей с тем же лагерем). По умолчанию 0 %. Сами лагеря каналов не меняются.
Разброс подписчиков: 0 — почти одинаковые аудитории; 1 — исходные числа
из списка; 2 — больший разрыв между небольшими каналами и крупными.
Этот ползунок сохраняет общую аудиторию выбранного количества каналов.
Изменение количества каналов само по себе меняет суммарную аудиторию.

Изменение только сложности сохраняет граф и выбранный стартовый канал.
Изменение сети сбрасывает стартовый канал, сохраняя выбранный вариант новости.
Во время распространения параметры менять нельзя.
Настройки и зерно генерации сохраняются вместе с текущим прохождением.
Продолжение игры восстанавливает ту же сеть при неизменном списке каналов.
